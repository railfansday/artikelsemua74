📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

A balance check and a bank reconciliation answer different questions. The balance check asks whether the rows you extracted from a statement reproduce its printed closing balance: opening plus credits minus debits. The reconciliation asks whether the bank account in your books agrees with the statement, once timing items such as an uncashed check are explained.

Mixing them up is expensive. Reconcile a badly extracted table and reading errors get mixed with genuine timing differences, so neither can be found cleanly. Run the arithmetic check, then the reconciliation. (Related: Using & Mixing Hugging Face Models with Gradio 2.0...)

Recent findings suggest that any nonzero value is a reading problem or a scope problem: wrong account, wrong period, a carried-forward line counted as a deposit. There is no "normal" difference in this check.

Sources indicate that A fictional statement closes at €2,210.10. In the books, a paper check for €150.00 written on September 9 has not been presented to the bank by the statement date, so the ledger demonstrates €2,060.10. That €150.00 gap is expected in a reconciliation and is explained by a list of outstanding items. It has no place in the arithmetic check, because the uncashed paper check never appears on the statement at all.

It has been revealed that suppose the extraction read a debit of 89.90 as 899.00. The extracted table now closes at 1,401.00, a gap of −809.10 against the printed balance. If you skip the balance check and go straight to reconciliation, that −809.10 lands in the same pile as the €150.00 timing item, and you end up searching your ledger for a transaction that never existed. Fix the reading first: the first nonzero row in the difference column points at it.

Industry observers note that A matching balance does not prove each row was read correctly: two swapped descriptions or two offsetting errors leave it intact. A clean reconciliation does not prove a document is authentic. Write down what you checked, for example "equation consistent for pages 1 to 4; descriptions not reviewed", so nobody reads more into a green cell than it states.

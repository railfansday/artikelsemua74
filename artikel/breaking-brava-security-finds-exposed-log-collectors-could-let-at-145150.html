Breaking: Brava Security finds exposed log collectors could let attackers tamper with breach evidence

UPDATED 09:00 EST / NOVEMBER 24 2026.

Sources indicate that A new report out today from security operations startup Brava Security Inc. find that more than 2,300 exposed log collectors at nearly 1,200 organizations accepted fabricated security events without requiring credentials, raising questions about the reliability of the data that security teams depend on.

Dubbed “Ghost Feeds,” the research is said to show that attackers able to write into those collectors may be able to tamper with the evidence a security team uses to investigate a breach.

Sources indicate that as part of the research, a decoy security information and event management system with no legitimate traffic was deployed on the public internet. Within about two hours, unknown parties had begun reading from the decoy. Attempts to inject fabricated events followed shortly after. The activity continued for at least two weeks. Sources indicate that following on from the decoy, the researchers sent a single harmless, uniquely marked event to internet-exposed log collectors running any of seven logging products, including Elasticsearch, Splunk and Fluent Bit. More than 2,300 of those endpoints were found to accept the event with no authentication required. The number of organizations affected may be higher still, according to Brava, since its researchers were able to identify the owners of only about a third of the endpoints. (Related: Deep Learning over the Internet: Training Language Mode...)

It has been revealed that results varied by platform, with about three-quarters of the exposed Elasticsearch clusters that responded accepting the test event. Nearly two-thirds of sampled TCP Syslog collectors also accepted it, as did 43% of identified Fluent Bit endpoints.

Sources indicate that splunk, the report notes, is a different story. Thanks to default authentication requirements, its HTTP Event Collector rejected 58% of test writes. The catch is that the primary forwarding port on a standard Splunk installation was shown in laboratory testing to accept unauthenticated events in plain text. More than 100,000 internet hosts listen on that port number, with 42% of a sample accepting the unauthenticated events.

According to recent reports, according to the researchers, the damage from forged telemetry can go well beyond false alerts. In one lab test, 13 cents’ worth of bandwidth generated enough data to exceed a Splunk daily license allowance by 2.39 times in 141 seconds. Should that happen repeatedly, search can be disabled while logs continue to come in, potentially leaving a security team unable to investigate.

In a recent development, “Security teams cannot afford to assume that everything appearing in their SIEM is trustworthy,” said Idan Basre, Brava’s co-founder and chief executive, who led product management for Microsoft Defender before starting the company. An attacker able to influence that evidence, he warned, could potentially “change the outcome of an investigation before anyone realizes the underlying data has been compromised.”.

Brava’s researchers also wanted to know what manipulated logs would do to AI-powered security operations. To find out, three popular open-source AI security operations center tools were given the same suspicious login scenario.

Industry observers note that all three initially identified the activity correctly. Once the researchers had injected 10 fabricated Windows events into the logs, the same suspicious login went unnoticed by all three.

Since AI investigators are “only as reliable as the evidence they analyze,” according to Brava co-founder and Chief Technology Officer Itay Gabbay, attackers able to write into the systems supplying that evidence may be able to influence what security teams and their AI agents end up dismissing.

According to recent reports, to help organizations check their own exposure, Brava is releasing ghost-telemetry-check, a free, open-source tool designed to test whether a logging pipeline will accept unauthenticated events. Detection rules for Splunk, Microsoft Sentinel and other platforms are also included in the release.

According to recent reports, brava formally launched earlier this month with $15 million in seed funding led by F2 Venture Capital and Pitango Venture Capital. Its platform is said to use multi-agent AI to generate the telemetry an attack would produce without carrying out the attack, showing companies which threats their existing defenses would miss.

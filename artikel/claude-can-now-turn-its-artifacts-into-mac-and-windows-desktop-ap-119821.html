Claude can now turn its artifacts into Mac and Windows desktop apps

🌐 Source: Thenextweb • 📅 25 Nov 2026 • ⏱️ 2 min read (456 words, 📖 Standard)
💡 Key Takeaways
  • Claude can now turn the artifacts it builds into desktop apps for Mac and Windows.
  • It has been revealed that after installation, an artifact gets its own icon and opens in its own window instead of inside Claude.
  • By default, an installed app can only do what it could do in a browser.
📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Claude can now turn the artifacts it builds into desktop apps for Mac and Windows. Anthropic began rolling out the “Install as app” feature in beta on Tuesday, on every plan, it remarked.

It has been revealed that after installation, an artifact gets its own icon and opens in its own window instead of inside Claude. It can still use Claude and the user’s connectors, and it updates itself whenever someone edits the underlying artifact. Customers do not need to package or sign the app, or set up an API key. Requests the app makes to Claude count toward the plan’s usage limits. (Related: The Reformer - Pushing the limits of language modeling...)

By default, an installed app can only do what it could do in a browser. It can ask for app permissions. These include sending notifications, adding a menu bar or system tray item, floating over other windows, or responding to keyboard shortcuts. (Related: Porting fairseq wmt19 translation system to transformer...)

Sources indicate that the highest level is full computer access. An app with it can run programs and read, change, or delete files without asking each time, according to Anthropic’s help page.

“Only allow it if you trust everyone who wrote the app. Anthropic doesn’t review apps before you install them,” the help page warns.

Users can only give full access to apps they made themselves, or, on Team and Enterprise aims, apps made by people in their organisation. Every permission covers one version of the app, so Claude asks again after each patch, even the user’s own edits. Code an app loads from another website can change without a new request, Anthropic remarked.

Recent findings suggest that the feature needs Claude for Mac or Windows, and customers need an internet connection and a Claude login to open an app. It is not available on Linux, the web or mobile, or to organisations with HIPAA-ready setups. It is on by default for Team aims, with full access off. On Enterprise plans it stays off until an owner turns it on.

Consumers cannot install artifacts built from templates, such as Claude Docs, Slides and Sheets. Anthropic staff have used the feature to build an image editor, a file manager, a folder organiser, a terminal and a performance monitor.

It has been revealed that the launch came the same day Anthropic let MCP servers ship skills and run tasks in Claude. It also published its Siren test, which checks whether Claude escapes weakened sandboxes, and last week added zero data retention to Enterprise Frontier Safeguards. Zero data retention does not apply to these apps, the help page indicates.

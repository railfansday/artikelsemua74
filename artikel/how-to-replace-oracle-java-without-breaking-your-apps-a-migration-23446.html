In the last post, we identified which machines have paid Oracle Java licenses. Now the practical question: how do you replace Oracle with a free alternative without breaking production?

According to recent reports, all Java alternatives (Eclipse Temurin, Amazon Corretto, Azul Zulu, OpenJDK) pass the same Java Compatibility Test Suite (JCT). If a version passes JCT, it's binary-compatible with Oracle's JDK for the same major version.

An app built and tested against Oracle JDK 11 will run on Eclipse Temurin JDK 11, Amazon Corretto JDK 11, or Azul Zulu JDK 11 without code changes. (Related: Tech Report: Scientists built the hardest AI test ever ...)

Pick one non-critical machine (dev VM or staging server).

The hard part isn't the technology—it's the operational discipline. Plan the rollout carefully, test thoroughly, and monitor closely.

I got tired of babysitting five coding agents, so I built a supervisor for them

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

I don't use one coding agent anymore. Depending on the task, I switch between Claude Code, Codex, Gemini CLI, OpenCode and a few others.

The tools themselves are great. The problem is everything around them: separate sessions, separate quotas, zero shared context. And the moment one of them hits a 429 mid-task, I'm the one copy-pasting context into another tool and re-explaining the problem from scratch. I was spending real time being a human message bus between my own tools. (Related: How to train a new language model from scratch using Tr...)

So I built Kooyu: a local-first personal assistant that sits on top of 10+ coding harnesses — Claude Code, Codex, DeepSeek, Gemini CLI, OpenCode, Cursor, ZCode, Kimi Code, Grok Build, pi — and supervises them.

Routing. Each task goes to the engine that fits it best, instead of whichever tab happens to be open.

Rate-limit handoff. When an engine hits a 429, Kooyu packages the live context — what was tried, what changed, what's left — and hands the task to another engine. The work continues instead of dying.

It has been revealed that arena mode. This is the feature I use most. Give Kooyu a problem and it races 2–3 engines on it in parallel, each in its own isolated Git worktree. You get a scorecard — diff plus test results — and merge the winner. It's a surprisingly good way to learn which engine is actually better at which kind of task, with evidence instead of vibes.

The boring-but-notable parts. Persistent local memory across sessions, background watches that cost zero tokens, and decision cards you can approve from your phone or IM when an agent needs a yes/no.

Everything runs on your machine. Code, memory and API keys never leave it. Sync between desktop, web, iOS, Android and IM is end-to-end encrypted (zero-knowledge), which is what makes "approve from your phone" safe to offer at all. (Related: The Age of Machine Learning As Code Has Arrived...)

Kooyu is MIT-licensed and open source. v1.0.0 just shipped.

Site: https://kooyu.app GitHub: https://github.com/sh2001sh/Kooyu.

If you also juggle multiple coding agents, I'd love to hear it: what would you want a supervisor to take off your plate — and what would it have to prove before you'd trust it with a real repo?

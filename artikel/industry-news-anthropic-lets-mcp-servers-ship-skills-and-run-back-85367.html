According to recent reports, anthropic has opened Skills over MCP in public beta, letting apps that connect to Claude ship playbooks alongside their tools. Tasks, for long background jobs, and Elicitation, which pauses for user input, are now generally available, with File Uploads coming soon.

Industry observers note that apps that plug into Claude through MCP can now also tell it how to use them, Anthropic said on Tuesday. The feature, Skills over MCP, is in public beta in Claude and Claude Code. (Related: Industry News: Fight to chair the GOP tests Trump’s clo...)

According to recent reports, MCP is the open standard Anthropic released two years ago to link AI agents to outside apps and data. Servers built on it already list the tools Claude can use. With skills, they can also ship step-by-step guides and best practices, which Claude loads only when needed. (Related: Tech Report: Woman known as Firefighting hero arrested ...)

Shopify uses skills to help Claude design and upgrade online stores, and HubSpot to onboard customers. Skills update with the server, so consumers have nothing extra to install. More apps are opening up, too: Canva opened its MCP server to all developers on Tuesday.

Recent findings suggest that the beta is on by default for Pro, Max and Ultra plans. Team admins can switch it on, and Enterprise support is coming soon.

Recent findings suggest that two other features are now generally available. Tasks lets a server run long jobs in the background while Claude keeps working, which ZoomInfo uses for deeper research. Elicitation lets a server pause and ask the user for input.

GitHub, for example, makes users type a repository’s name before an agent deletes it. Supabase confirms costs before creating a paid project. A fourth feature, File Uploads, will soon let Claude send PDFs, spreadsheets and images to servers.

It has been revealed that the features are part of MCP, so servers that support them also work in other compatible apps. Anthropic indicates MCP now sees over 700M SDK downloads a month. In August, OpenAI and four rivals agreed on a standard for packaging skills and MCP servers.

Skills carry risks, too. That same month, researchers found malicious agent skills that stole passwords and keys after about 1.7 million installs.

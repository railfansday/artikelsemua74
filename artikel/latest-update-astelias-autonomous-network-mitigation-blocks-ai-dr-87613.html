Recent findings suggest that exposure management company Astelia Inc. today announced the launch of autonomous network mitigation, a fresh capability that allows organizations to block artificial intelligence-driven exploits at the network level, even when a patch isn’t available or can’t be applied. According to recent reports, the new capability has been designed to address what Astelia claims is the problem of frontier AI models cutting the time to exploit to almost zero, leaving manual triage and remediation unable to keep up. Astelia argues that autonomous remediation isn’t a viable option for large enterprises, where every patch requires a change window so it doesn’t break vital business processes. In many cases, there is also no patch to apply because the vendor hasn’t released a fix yet or, for older and end-of-life systems, never will. (Related: GTA 6 hacker released from prison after judge warns him...)

“For years, security teams have been told to patch faster,” noted co-founder and Chief Executive Alon Noy, adding that the advice “stops working when the exploit arrives before the change window does.”.

In a recent development, autonomous network mitigation is designed to block the path an attacker would use to reach a vulnerable system instead of changing the system itself. Mitigations are applied automatically within policies the organization sets. Nothing on the asset is changed, allowing business-critical systems, including operational technology, to stay online.

Underpinning the service is Astelia’s reachability analysis, which maps an organization’s real network topology and applies agentic AI to analyze the requirements of each exploit. By correlating exploit conditions with network topology, the platform identifies which vulnerabilities are reachable by attackers and through which paths. In one enterprise deployment, approximately 40 million vulnerabilities were reduced to fewer than 2,000 that were reachable, according to the tech giant.

Sources indicate that key features of autonomous network mitigation include the ability to identify the most effective choke point on an attack path and drive the mitigation through an organization’s web application firewall or intrusion prevention and detection system. A single rule at a choke point is remarked to protect every vulnerable server behind it, compared with one change per server when patching. Because mitigations are only applied to paths that have been proven reachable, the service doesn’t add rules for exposure that doesn’t exist.

In a recent development, every mitigation applied by Astelia can also be rolled back, something that isn’t always possible with a patch. That is said to allow teams to act quickly without putting business operations at risk.

Recent findings suggest that autonomous network mitigation can be deployed through Astelia Agents, the tech giant’s suite of AI agents, as a dedicated agent that applies mitigations on its own. The agent can also be connected with other agents to respond to urgent threats such as zero-day vulnerabilities and critical disclosures. Astelia gave the example of the PHP2Shell remote code execution flaws disclosed in October, which left end-of-life PHP servers with no official fix.

Each organization sets its own guardrails on how mitigations are applied. Consumers can require human approval for specific environments or actions, according to the company. Every action is logged and can be audited. Analysis on the Astelia platform continues to run on read-only integrations, with mitigation actions using scoped permissions that each organization enables and controls.

Autonomous network mitigation initially supports web application firewall and intrusion prevention and detection rules, with support for firewall rules planned in the future.

Founded in 2024 by former leaders of the Israeli National Red Team, Astelia is a venture capital-backed company that raised $35 million in combined seed and Series A funding in February. Investors in the company include Index Ventures, Team8 and Holly Ventures.

After a hacker stole customer data, Binance founder Changpeng Zhao advised 1Password consumers to change all the passwords stored in the service.

1Password offered different advice about what users should do after the incident was disclosed on Nov. 25. The password management service said hackers hadn't gained access to the passwords stored in users' vaults, so there was no need to reset them. According to recent reports, "If you use 1Password, recommend you to change ALL your passwords. It's a pain in the neck, but necessary," Zhao mentioned on X, replying to a post from Coin Bureau about the breach.

If you have a crypto exchange login stored in 1Password, this distinction is vital.

Scammers could still use the stolen email addresses to contact people they know are 1Password users. (Related: Simple considerations for simple people building fancy ...)

In a recent development, 1Password started investigating on Nov. 19 after detecting signs of possible unauthorized access to an employee's corporate GitHub account.

From there, the hacker was able to steal private source code and inject malicious code into 1Password's backend services. The malicious code then downloaded certain administrative data about customers.

Industry observers note that 1Password publicly disclosed the breach on Nov. 25, six days later.

The tech giant did not specify how many customers were affected or explain exactly how the hacker managed to take over the employee's account.

The stolen data included customer names, login email addresses, account and user IDs, and timestamps indicating account creation and last use.

The hacker also gained access to 1Password's software development and deployment systems.

1Password disabled the compromised employee's GitHub account and revoked the stolen access token.

The firm also restored a clean version of the affected service and revoked or replaced potentially exposed internal credentials.

1Password also engaged independent security experts to review its response.

1Password recommends that customers check the 1Password app or type the firm's website address directly into their browser if they receive an unexpected invitation or recovery message.

The tech giant says it will never contact users to request their account password or Secret Key.

Upgrade: 1Password claims that there is no need to change one's 1Password account password or any of the passwords saved in one's vault. No customer passwords were exposed in this incident.

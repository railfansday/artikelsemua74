📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

It has been revealed that hi, I'm Bhavesh, a freelance motion designer in Rajkot, India. I wanted a CRM that can use AI but runs inside a Google account people already have, with no server to host and no upcoming login. So I built Finalsay. This is version 0.1.

125 automated tests pass. They run against small stand-ins for the Google services, so they check Finalsay's logic, not that Google behaves like my stand-ins. (Related: Google files patent for AI-generated TV channel that us...)

I also installed it once, on one personal Gmail account, on 26 November 2026. Setup, email capture, the Today list, approvals, reply drafts and the phone page worked there, and the built-in self-check passed 13 of the 13 checks that applied (2 were skipped because AI and calendar were off). (Related: Defeat Ragdolls for Powers codes (November 2026)...)

The template Sheet came later, on 27 November. I checked that making a copy of it brings the script along and that the CRM menu appears in the copy. I have not run Set up on a copy yet.

Not verified yet: a real phone, any real AI key, the daily trigger actually firing, a second person using it, the Approve buttons inside the board and phone pages, and HTML-only emails. STATUS.md in the repo lists all of it.

In a recent development, I would like feedback on the install and on what is missing for your kind of work. If the install fails, please paste the lines from the Self-check tab into a GitHub concern.

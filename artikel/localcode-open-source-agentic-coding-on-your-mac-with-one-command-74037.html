Agentic coding. Local models. On your Mac.

Upgrade with uv pip install -U localcode.

To use the running model from another local app, open /server or run localcode api for its OpenAI compatible endpoint. See the Local API guide. (Related: How to train a new language model from scratch using Tr...)

Choose from 12 models and 169 quant options for coding, image input and typed decisions. Models download from Hugging Face. Downloads run in parallel and can resume if interrupted. Switch with /models. LocalCode recommends the most capable one that fits your Mac's memory and marks it with a star. (Related: Block Sparse Matrices for Smaller and Faster Language M...)

According to recent reports, speed: Gemma 4, Qwen 3.6, Muse Glimmer and Qwen 3.8 draft tokens with the vendor's own speculative drafter, which downloads with the model. The model server's GPU kernels ship precompiled, so the first start after an install is quicker.

What LocalCode adds on top of the stock model server to make local models faster and better at coding.

Inference is local. Three features use the network: model downloads, the web_search and web_fetch tools, and any MCP servers you add. See Network Boundary for the full list.

Powerful, personal AI should work for everyone, on any device, anywhere. That means running it locally. localcode is a first step.

Research artifact. Not maintained and not accepting contributions.

A Lean 4 proof of the Riemann Hypothesis and of the Generalized Riemann Hypothesis for Dirichlet L-functions, built on Mathlib and using only the axioms propext, Classical.choice and Quot.sound. (Related: How to train a newly introduced language model from scr...)

It has been revealed that the proof is based on Levent Alpöge's, with Claude (https://alpo.ge/remark.pdf). This repository is a shorter version, produced in collaboration with my colleagues at Anthropic, and Claude. (Related: Tech Report: Transformer-based Encoder-Decoder Models...)

Each folder is its own Lake project with its own README.

According to recent reports, needs Lean v4.35.0 and Mathlib at commit 56a00585. In either folder:.

A build takes one to two hours on 12 cores with 24 GB of memory (about 85 minutes more if the Mathlib cache is missing).

In a recent development, the proof has passed machine checks only, listed in each folder's README. No mathematician has read it through, and no paper comes with it.

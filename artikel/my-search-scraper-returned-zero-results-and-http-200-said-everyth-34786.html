I built MiniSERP to learn how a search results API works underneath. It's a small Rails 8 API that takes a Google results page and turns it into clean JSON: title, link, snippet, position.

Sources indicate that the first version worked on the first page I tested. I wrote the specs and they passed, and I thought the parser was done.

In a recent development, then I saved a second results page with a different query and ran it through the same parser. I got back an empty array with HTTP 200. (Related: How to generate text: using different decoding methods ...)

It has been revealed that an empty array with a 200 looks exactly like "Google found nothing for this query." Nothing crashed and nothing demonstrated up in the logs. If I had shipped this, every search would have come back empty, and the API would have reported success every time. (Related: Latest Update: Hyperparameter Search with Transformers ...)

I want to share my open-source Flutter MCP Suite — a set of 5 Dart and Flutter packages for building AI agents with Model Context Protocol (MCP), generative UI (A2UI), and local on-device models.

In a recent development, to be honest, I did not write all this code by hand. I designed the structure, guided the work, and maintain the packages using AI coding agents — mainly Antigravity, and now also my own open-source tool TealKit Coder, which is built on top of dart_mcp_core.

Using the packages every day inside a real coding agent helped find many real bugs quickly — like context compression loops, local model template errors, and Android file-saving complications — so we could fix them and add tests right away. In a recent development, the base package is dart_mcp_core. It is pure Dart with no Flutter dependencies (160/160 pub.dev points, 99+ unit tests).

Because it does not depend on Flutter, the same agent engine works everywhere:.

With flutter_a2ui_mcp (using a2ui_flutter ^0.5.0 and a2ui_core ^0.9.0), the AI can show interactive Flutter widgets directly inside the chat instead of only plain text.

In v1.2.1, it uses A2UI 1.0 Express by default:.

Express uses about half as many tokens as raw JSON, checks the output against your widget catalog, and still falls back to normal JSON if a smaller model outputs JSON instead. (Related: Steam is pitting 10 years of Game of the Year winners a...)

In a recent development, if you want to run models offline on Android, iOS, or Desktop, flutter_ui_mcp_embedded connects llamadart (^0.21.0) to dart_mcp_core. It supports both GGUF (llama.cpp) and LiteRT-LM (.litertlm) models, and includes a HuggingFace model search dialog.

If you try it out or have any feedback, feel free to leave a comment or open an matter on GitHub!

According to recent reports, perplexity has added Time Machine to its Search and Context APIs, letting agents see the web as it was up to 365 days ago so forecasting tests are not spoiled by hindsight. Perplexity has released Time Machine, a tool that lets AI agents search the web as it looked on a past date, the company remarked on Wednesday. It arrived a day after Epochal, a startup from three of xAI’s co-founders, launched a similar product. (Related: Hyperparameter Search with Transformers and Ray Tune...)

Both target the same problem. An AI agent asked about a past election or earnings call can simply look up the result. That makes it hard to test how well it really predicts.

Time Machine adds a date cutoff to Perplexity’s search and page-reading tools for developers, so results come from copies saved before that date. Perplexity’s cutoffs reach back 365 days. Epochal states its archive spans more than 30 years.

According to recent reports, perplexity claims it used the tool to train an AI model to forecast 2026 political events listed on Polymarket. In its own test, the trained model scored 0.80, just above the market’s 0.79.

According to recent reports, it also indicates fewer of its pages leaked later information than rival Exa’s, at 0.25% against 1.10% in one test. That was judged by Perplexity’s own automated checker. Time Machine costs the same as Perplexity’s other API calls.

It has been revealed that web tools built for AI agents are multiplying. On the same day, Cloudflare began letting websites offer agents their own search.

Archives of the web are becoming contested ground. More than 241 news outlets now block the Wayback Machine to keep AI companies away from their old articles.

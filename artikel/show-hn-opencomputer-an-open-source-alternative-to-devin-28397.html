The open-source Devin alternative: a coding agent your team works with in Slack, on its own computers, in your cloud or ours.

Cloud | Self-hosting | Docs | Website | Benchmark | Community | X. (Related: My Journey to a serverless transformers pipeline on Goo...)

OpenComputer is the open source, self hostable alternative to Devin. Mention @Computer in a Slack thread with a task, it works on its own computer, you & your team can watch and steer it as it goes, and the result lands as a pull request.

It is open source from the compute layer up, so you can run all of it in your own cloud account, or start on OpenComputer Cloud in two minutes.

We built it to feel as fast as Claude Code on your laptop: in our benchmark it opens PRs 3.3x faster than Devin. (Related: Block Sparse Matrices for Smaller and Faster Language M...)

OpenComputer is built to be simple to self-host without giving up scale or security. The whole stack runs on a single VM, which we recommend locking down to outbound-only network access.

In a recent development, the VM runs the gateway, Calvin: a thin bridge that listens for Slack events and starts a session with Claude Code, Codex or OpenCode, depending on your configuration. Each session is isolated with rootless Podman. Its state is written first to the VM's local disk, then persisted to a git-backed store.

Sources indicate that the rest of the stack runs on Cloudflare Workers and Durable Objects. Support for Fly and other platforms is coming soon.

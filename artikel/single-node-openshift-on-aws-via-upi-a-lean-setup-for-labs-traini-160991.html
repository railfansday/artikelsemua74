Spinning up a Single-Node OpenShift (SNO) cluster on AWS for training or lab environments doesn't always require heavy Terraform or CloudFormation scaffolding. With User-Provisioned Infrastructure (UPI), you stay close to the actual mechanics and see every stage of the cluster coming up.

Once the cluster is up, tighten your security group rules, remove the Ignition files from the web server (as they contain sensitive data), and raise the DNS TTL back up. For dynamic PVC provisioning, install Red Hat LVM Storage (LVMS) via a Subscription in the openshift-storage namespace.

For workshops and lab environments, the UPI route on AWS is great when you want visibility into bootstrap, cutover, and storage without hiding behind black-box automation.

This is the sort of game where not saving can undo hours of progress, which is absolutely gutting when it happens. There are also questions about the GTA 6 autosave function and how it works, which we can also help explain.

Here's the lowdown on exactly how to save in GTA 6 and how the game's autosave works — and why it might seem like it isn't working at all.

To manually save in GTA 6, you need to pause the game, navigate to the "Game" option on the menu, then select "Save." This will show 15 save slots, of which you can choose any to save your game. If you suspect you may want to load an old save to play through missions another way or make a different choice, I'd recommend using a rolling save system, where every time you save, you overwrite the oldest save file you have. However, there are reports that this hasn't been working properly, so you should be manually saving your game on a regular basis in case the autosave lets you down.

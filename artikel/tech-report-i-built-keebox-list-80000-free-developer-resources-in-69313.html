According to recent reports, how many browser tabs do you open just to find a good tool for something? A CLI replacement, a free hosting tier, a Rust crate, a landing-page template… The answers exist, but they're scattered across hundreds of awesome lists, blog posts and bookmarks.

So I built KEEBOX LIST™ — a free, open-source directory that puts them all in one place, so you spend less time searching and more time building. (Related: Simple considerations for simple people building fancy ...)

AI & Data — AI & LLM tools (local models, agents, MCP servers, RAG), data engineering (Airflow, dbt, Spark, Metabase) and databases. (Related: Block Sparse Matrices for Smaller and Faster Language M...)

Languages — Python, Go, Rust, Java & Kotlin, C# & .NET, PHP, Node.js, npm and Swift.

Web & Mobile — React, Vue, Svelte, Next.js, APIs (REST, GraphQL, gRPC), Flutter, React Native, iOS, Electron, plus templates and starters.

Infrastructure — DevOps & self-hosting, cloud free tiers, Linux & terminal tools, security, and testing & QA.

Creative & Hardware — design & UI assets, game dev (Godot, Bevy, Phaser), IoT (Arduino, ESP32, Home Assistant) and Web3.

Tools & Learning — roadmaps and free courses, cheat sheets, free online tools, editor extensions, podcasts and newsletters, macOS apps, and a section of resources in Spanish 🇭🇳.

KEEBOX is a static site built with Material for MkDocs, following its official structure. Everything lives in plain Markdown on GitHub, so contributing is as simple as opening a pull request.

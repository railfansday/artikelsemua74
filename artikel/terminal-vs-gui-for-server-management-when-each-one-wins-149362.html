According to recent reports, for server management, pick the terminal or a GUI by task, not by habit. The plain terminal is best for small, quick tasks and needs no third-party app. A GUI is best for browsing files and handling several servers in tabs. Some GUI apps, like Termius and CtrlOps, also run saved scripts.

According to recent reports, your ssh client opens one encrypted connection, asks the server for a shell, sends your keystrokes and gets text back. For your session, the server starts only your shell and the commands you run, next to the SSH service.

In a recent development, inside that connection, SSH uses channels. RFC 4254, the SSH connection standard from 2006, claims: "All terminal sessions, forwarded connections, etc., are channels." It adds: "Multiple channels are multiplexed into a single connection." A channel can ask for an interactive shell or for one command:.

It has been revealed that A GUI SSH client uses the same SSH protocol and server account as the ssh command. It opens more channels for you: a shell per terminal tab, short commands that read things like disk use, and, in most file browsers, SFTP.

SFTP itself is part of SSH: on OpenSSH servers, sshd starts sftp-server through its Subsystem option.

Sources indicate that the Termius docs, for example, say that for autocomplete it "opens additional exec channels next to the main shell channel". In CtrlOps, gauges for CPU, RAM and disk show "the numbers top, free -h and df -h / give you, without running them".

According to recent reports, so the SSH GUI vs command line choice is not about access: a GUI client does not unlock anything the terminal cannot do. It types the commands for you and shows the answer as a list or a gauge. It needs no fresh port on the server, because it uses the SSH service already running.

A web panel runs on the server itself: a service, a port and a login page that you open in a browser.

Recent findings suggest that by default, Cockpit listens on port 9090 (Running Cockpit) and "uses your system's normal user logins and privileges" (Cockpit). Thanks to systemd socket activation, it runs only on demand. Webmin listens on port 10000 by default, and its docs say it "runs with full root privileges" (Webmin docs). A GUI for a Linux server can run in three places. Two are on the server: a desktop or a web panel. The third is an app on your own computer that connects over SSH.

There is no Ubuntu Server GUI by default: the server image "will not install a graphical user interface" (Ubuntu 26.04).

RHEL differs: "By default, the Server with GUI base environment is selected" (RHEL 9 docs), so pick Server or Minimal Install there.

Sources indicate that A desktop costs memory. Ubuntu Desktop 26.04.1 LTS asks for 6 GB of RAM (download page). The Ubuntu Server 24.04 LTS installer needs 1.5 GB (requirements). The versions differ, but the gap is clear.

Recent findings suggest that A desktop also adds packages to patch. A STIG is a security checklist from DISA, the US Defense Information Systems Agency. The RHEL 9 STIG (v2r8, rule RHEL-09-215070) states: "A graphical display manager must not be installed on RHEL 9 unless approved.".

Rapid7 published research concerning Webworm, a China-aligned advanced persistent threat (APT) group first reported on in 2022 and believed to be active since at least 2017. Webworm's activity predominantly targets government organizations, with an emphasis on Europe. The group has also been tracked as Erudite Mogwai and Space Pirates. Webworm has been known to deploy the open source SoftEther VPN on previously compromised government networks. While SoftEther is a legitimate multiprotocol VPN, threat actors abuse its capabilities in attacks. Webworm actors in particular include a "VPN Bridge" component allowing them to link a victim's internal network directly to attacker-controlled servers to facilitate long-term access.

The fresh research, published on Nov. 19, covers what Rapid7 researcher and blog post author Milan Spinka called "a so-far unknown custom SoftEther-based tool, which implements various tricks to hide itself from security tools, and which we attribute to Webworm with moderate confidence.".

Related:'TheMailer' Phishing Kit Puts AI in the Driver's Seat.

Rapid7 has identified a range of samples of the tool, which is internally described as "NtMonitor." The tool is a modified build of SoftEther VPN Bridge compiled for Windows x64 and appears to be specifically designed to disguise legitimate SoftEther VPN software as a benign network monitoring utility so the attacker can maintain long-term, stealthy access to a compromised network while evading detection tools made to recognize standard SoftEther software artifacts.

At its core, Spinka wrote, it appears the attacker "methodically analyzed SoftEther's detection surface and implemented countermeasures to all of the easy ways a detection engineer may target it.".

Attackers changed the metadata and internal branding to refer to generic "Network Monitor Software," for example. Additionally, they changed internal string references to refer to "NtMonitor VPN" like debug banners, service names, registry pages, and firewall rule names (though this was inconsistently applied); renamed the HTTP endpoints used by the VPN protocol; changed the handshake watermark so standard SoftEther detection signatures wouldn't pick it up; stripped down a core file (hamcore.se2) and embedded it inside the executable; and renamed and encrypted SoftEther's plaintext configuration file with a custom cipher.

Dark Reading contacted Rapid7 for additional information, but the research team was unavailable at press time.

According to recent reports, one of Webworm's primary initial access methods appears to be exploiting vulnerabilities through external Web-facing applications, based on prior vendor research and the APT's affinity for vulnerability scanner Nuclei. Defenders wary of Webworm should prioritize internet-facing patching, Web Application Firewall (WAF) enforcement, and strict network egress controls.
